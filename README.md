### 🛠️ What I work with

**Hardware**: KiCad · Altium · schematic & multi-layer PCB design · analog front-ends & filters · Gerbers / pick-and-place for production

**Firmware**: C · Zephyr RTOS · nRF Connect SDK · STM32 (HAL, CubeIDE, CMake) · RP2040 · Python
